# Learn with Jiji – Backend API

This project is a backend API created as part of the *VeidaLabs Software Developer Hiring Assignment*.

It provides a simple API where users can ask a question and receive:
- A short AI-style explanation
- Related learning resources (PPT / PDF / Video)

---

## 🚀 Tech Stack
- Node.js
- Express.js
- Supabase (Database & Storage)
- Postman (API testing)
